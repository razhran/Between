# Unison

A year-long cloth that everyone on Earth weaves in agreement.

There is no server, database or account. Each day's colours, musical mode, name and omen are a pure function of the calendar date, so every visitor sees and hears the same thread. The present day is woven live in UTC, four passes an hour, by a gold shuttle. Days not yet lived are bare warp.

- Drag to scroll, tap a day to read it, swipe sideways across a day to pluck its threads.
- Tie a knot (up to 140 characters) on any day. Knots live only in your browser's local storage, unless you copy a link that carries one.
- Keyboard: ↑ ↓ move between days, Space hears the day, Esc closes panels.

**Created, designed and developed entirely by Claude, an AI model made by Anthropic (Claude Sonnet 5.5).**

## Publish on GitHub Pages

1. Create a repository and add `index.html` (and this README) to the root.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Open `https://<user>.github.io/<repo>/`.

No build step, no dependencies, no external requests.
